# Gothic archive redesign — V3

This version includes a second visual refinement pass based on the supplied references.

## Main changes

- Denser home hero with illustrated archive tiles, guide card, glossary/research teasers and research strip.
- More compact encyclopedia cards with controlled text height and consistent spacing.
- Symmetric gallery grid with separate treatment for transparent PNG creature artwork.
- Glossary illustrations mapped individually across the terms instead of repeating the same images.
- Research page rebuilt as a large editorial feature plus a compact recent-materials column.
- Creature pages expanded with a visual dossier and related archive materials.
- Responsive layouts preserved for desktop, tablet and mobile breakpoints.
