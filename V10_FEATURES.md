# V10 — Interactive Archive Experience

Implemented features:

- Shared-element page transitions for creature cards and dossiers.
- Interactive mythology atlas on the home page.
- Random archive material selector in desktop and mobile navigation.
- Scroll-aware reading timelines on creature and research pages.
- Cinematic full-screen gallery with filmstrip, zoom, dossier toggle, keyboard and swipe navigation.
- Reduced-motion fallbacks and responsive mobile layouts.

Local check:

```bash
npm install
npm start
```

Production check for GitHub Pages:

```bash
npm run build -- --base-href=/demonology-archive/
```
